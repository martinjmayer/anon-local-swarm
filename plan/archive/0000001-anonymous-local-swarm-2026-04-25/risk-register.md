## Risks

| ID | Category | Description | Likelihood | Impact | Mitigation | Status |
|----|----------|------------|------------|--------|-----------|--------|
| R-001 | technical | SLM output (3-7B models) produces malformed JSON or unparseable structured output, causing task failure | high | medium | Prompt engineering with few-shot examples; output parser with fallback; self-correction loop for GO_CODE; retry with explicit format instruction | open |
| R-002 | technical | VRAM OOM if `keep_alive: 0` is not honoured by Ollama in a specific version | medium | high | Enforce keep_alive in every request; add Ollama version check at startup; monitor VRAM via Ollama API | open |
| R-003 | technical | Cascading prune fires on a false-negative viability score from phi-4:mini | medium | medium | Configurable VIABILITY_THRESHOLD; log score to obs.db for operator review; operator can manually re-seed pruned branches | open |
| R-004 | technical | Recursive cascading prune on a deep branch (depth 5) causes SQLite write contention | low | medium | Use SQLite WAL mode; serialise prune writes through a single goroutine | open |
| R-005 | technical | Context sidecar JSON grows large enough to exceed model context even after compression | low | medium | Cap sidecar size; emit SUMMARY at 70% threshold; SmolLM3 is fast and cheap to invoke | open |
| R-006 | technical | MCP server process crashes or becomes unresponsive mid-run | medium | low | MCP client detects timeout; tool call returns error; task proceeds with degraded context; obs.db logs the failure | open |
| R-007 | technical | Reddit API OAuth token expiry mid-run causes mcp-reddit authentication failures | medium | low | mcp-reddit refreshes token on 401; if refresh fails, tool call returns error gracefully | open |
| R-008 | technical | DuckDB write performance degrades under high event volume (many rapid task transitions) | low | low | DuckDB is columnar append-only — handles high write throughput well; monitor event write latency | open |
| R-009 | operational | Operator forgets to pre-pull required Ollama models before starting the swarm | high | high | Orchestrator checks model availability at startup via Ollama API; logs missing models and exits with clear message | open |
| R-010 | operational | Output directory is not writable when swarm reaches terminal state | medium | medium | Check output directory writability at project start; fail fast with clear error rather than at deposit time | open |
| R-011 | operational | Self-correction loop exhausts MAX_DEPTH before fixing a build error | medium | medium | Logged as `failed` (not pruned); operator can inspect stderr chain in obs.db and manually re-seed with corrected prompt | open |
| R-012 | security | API credentials leak into task payloads, context sidecars, or obs.db log | low | high | Credential scrubber in obs component; credentials sourced only from env vars; no credential interpolation in prompt templates | open |
| R-013 | security | mcp-reddit exposes a write-capable endpoint if SDK defaults allow it | low | high | Explicit tool registration — only read tools registered; no write tool implementations exist in codebase | open |
