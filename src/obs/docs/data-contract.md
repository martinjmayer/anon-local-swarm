## Tables

### events

| Column | Type | Nullable | Default | Constraints |
|--------|------|----------|---------|------------|
| id | UHUGEINT | no | auto | PK, DuckDB sequence |
| timestamp | TIMESTAMPTZ | no | now() | not null |
| event_type | VARCHAR | no | — | CHECK IN ('task_transition', 'vram_swap', 'cascading_prune', 'self_correction', 'context_compression', 'mcp_tool_call', 'output_deposit', 'orchestrator_start', 'orchestrator_stop') |
| task_id | VARCHAR | yes | NULL | UUID of related task (NULL for system events) |
| task_type | VARCHAR | yes | NULL | DECOMPOSE / RESEARCH / GO_CODE / VIABILITY_REVIEW / SUMMARY |
| from_status | VARCHAR | yes | NULL | Status before transition |
| to_status | VARCHAR | yes | NULL | Status after transition |
| model_tag | VARCHAR | yes | NULL | Model involved in event |
| depth | INTEGER | yes | NULL | Task depth at time of event |
| detail | JSON | yes | NULL | Event-specific payload (scores, error messages, counts — NO credentials) |

**Indexes:**
- PRIMARY KEY on `id`
- INDEX on `timestamp` — time-range queries
- INDEX on `task_id` — per-task history queries
- INDEX on `event_type` — filter by event category

**Relationships:**
- No foreign keys — obs.db is independent of swarm.db by design
